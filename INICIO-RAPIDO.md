# 🚀 Início Rápido

## ▶️ Iniciar

```bash
python3 launcher.py
```

**Pronto!** O launcher detecta tudo automaticamente:
- ✅ Sistema operacional  
- ✅ ngrok (se instalado, ativa streaming)
- ✅ Interface gráfica disponível

## 📱 Modo Streaming (Automático)

Se ngrok instalado → QR Code aparece automaticamente no canto superior direito

### Instalar ngrok:
- **Linux:** `sudo snap install ngrok`
- **macOS:** `brew install ngrok/ngrok/ngrok`  
- **Windows:** https://ngrok.com/download

## 👁️ Visitantes (Somente Leitura)

Quem acessa via QR Code:
- ✅ Vê timer em tempo real
- ❌ NÃO pode controlar

Banner roxo = modo visualização

## 🌐 URLs

**Você:** http://localhost:8080  
**Visitantes:** Escanear QR Code (aparece automaticamente)
